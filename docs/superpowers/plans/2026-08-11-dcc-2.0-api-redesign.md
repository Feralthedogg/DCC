# DCC 2.0 Public API Redesign Implementation Plan

> Exact implementation details live in the reviewed Task 7–15 briefs under
> `.superpowers/sdd/2026-08-11-dcc-2.0-api-redesign/`. This plan fixes execution
> order, dependencies, gates, and commit boundaries. Older plan snapshots with
> 231 endpoints, a final 60/284 REST surface, a fixed 283 Bot macro count,
> public flow init/deinit, a Bot name field, or an inline runner are obsolete.

## Global rules

- Work test-first: register and demonstrate the focused RED contract before
  production changes, then make it green without weakening assertions.
- Preserve unrelated user changes and do not edit the ignored progress ledger.
- Do not push, tag, publish, or create a release unless explicitly requested.
- Use C11 production code and compile public headers as C11 and C++17.
- LLAM remains exactly 2.2.0; final version is 2.0.0 Stable/SOVERSION 2.
- Run clean normal/sanitizer/install/package builds at risk-appropriate
  checkpoints; never reuse a dirty staging/install tree for release evidence.
- All Task 14 public removals/signature/layout replacements land atomically with
  Task 15's ABI-major/baseline reset.

## Task 15 — compatibility, documentation, performance, and release gates

Authoritative brief: `task-15-brief.md`.

### Baselines and reference

Generate from the final installed header tree:

- the exact previous-Stable compat-base pin and reviewed 1→2 removed/changed
  external/inline/type/macro ledger;
- every installed-header FunctionDecl classified as `DCC_API` external or
  complete public static-inline, with plain extern/storage ambiguity forbidden;
- every installed header's transitive external/inline/type/macro reachability
  in all 12 exact platform/language/build-role profiles;
- per-profile CMake package/target/helper/interface and pkg-config module/
  Cflags/Libs semantics;
- external symbol names and full declarations;
- all lowercase/uppercase public static-inline callable signatures;
- every typedef and enum value;
- every public record's orthogonal layout/direction/lifetime/writer/append/
  stride classification plus prefix and lifecycle;
- a compiler-independent conditional-definition artifact for all installed
  public `DCC_*` macros per owner header;
- exact resolved macro artifacts for the 12 POSIX/Clang and Windows/ClangCL,
  C/C++, static/shared-build/shared-consumer profiles;
- focused canonical POSIX/static Bot macro budget artifacts.

For `major_reset`, reconstruct v1.5.0 header artifacts and matching shared-
library exports from the pinned compat-base. Computed removed/changed keys must
equal the reviewed ledger exactly; every unlisted prior item uses the normal
same-major structural comparator. Current additions exist only through fresh
final baselines.

The same-major record comparator freezes non-layout axes, stride, initializer/
empty predicate, cleanup/consume identity, ownership anchor/minimum size,
logical groups, ownership/producer boundary, and existing field meanings/units
as well as layout. The header-reachability gate requires each prior installed
path and a matching-profile superset of its previous transitive public keys;
lost re-exports are fatal.

The same-major package gate freezes existing CMake/pkg-config consumption
semantics, enforces `Requires.private: llam >= 2.2.0` (or a verified direct-lib
receipt), resolves exactly one real LLAM target header with version >=2.2.0 and
ABI major 2, rejects dependency-floor overrides, and builds/runs the unmodified
compat-base consumers against only the new install prefix. The 1→2 reset seeds
this DCC-2 package baseline.

For the initial 1→2 reset, check the exact DCC 1 removed/changed ledger, current
artifact freshness, and synthetic smaller-DCC2-prefix canaries against previous
Stable `v1.5.0` at `6ba1e29a45ec3617cf17e05b716c54b8094bbf96`.
For later 2→2 releases, pin the
latest previous Stable v2 tag/commit and run actual old-header/new-library
probes. `origin/main` is ancestry evidence only; compat-base equal to HEAD is
fatal. Missing remote, pinned compat-base, compiler/profile, symbol inspector,
manifest, or mode-appropriate probe input is fatal. Compare resolved macro
expansions only within a matching profile.

Document every external/inline callable, macro, typedef/type, field, and enum
enumerator. Generate deterministic per-header reference pages and compile every
marked complete C/C++ snippet against a clean install. Primary docs must say
“typed request, raw result” and may describe opt-in owned response decoders only
as a post-2.0 roadmap.

### Performance and source package

Run at least three warmups and 30 paired AB/BA timed batches per workload.
Compute batch `ns/op`; median/p95 use Hyndman-Fan type 7 and CV uses sample
standard deviation. Fail CV over 5% after two reruns, median regression over
10%, p95 over 20%, or deterministic allocation/copy growth.

Source-package audit requires explicit clean extracted root, reference repo,
full pinned previous-Stable compat-base hash, a matching-toolchain shared
library built only from that compat-base, and a shared library built only from
the archive, plus both build receipts and a compatibility-provenance bundle. No
`.git` or binary check is silently skipped inside the extracted tree.
